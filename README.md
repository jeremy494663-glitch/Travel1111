# 釜山慢遊 · Busan Days

以手機為主的繁體中文釜山自由行規劃 App，使用 HTML、CSS 與 JavaScript，無須安裝套件或建置。

## 功能

- 四天三夜行程、景點收藏與編輯。
- NAVER Map 景點、飯店與交通查詢連結。
- 交通、海鮮與豬肉湯飯等美食規劃，附參考影片來源。
- 桃園往返釜山的機票比較及訂購網站。
- 桃園機場四天停車費試算。
- 南浦、西面、海雲台飯店比較：地鐵距離、三晚費用、房型與訂房網站。
- 新台幣記帳、預算與支出明細；舊韓元支出保留原額，可調整換算匯率。
- 資料自動保存在目前瀏覽器的 localStorage，不會自動跨裝置同步。

## 本機啟動

安裝 Node.js 後，在專案目錄執行：

```sh
node preview.cjs
```

瀏覽器開啟 `http://127.0.0.1:5173`。

## 檔案

- `dist/`：完整靜態網站，可直接交給靜態網站服務部署。
- `dist/app.js`：主要頁面、行程、收藏與記帳。
- `dist/logistics.js`、`dist/naver.js`：交通食宿與 NAVER Map。
- `dist/food.js`、`dist/flights.js`、`dist/hotels.js`：美食、機票停車與住宿比較。
- `dist/ledger.js`：台幣記帳與舊韓元記錄換算設定。
- `preview.cjs`：本機預覽伺服器。
- `mobile-update.cjs`：先前開發的版面遷移工具；目前網站已完成更新，正常使用不需執行。
- `.openai/hosting.json`：既有 Sites 部署設定，不包含登入憑證。

## 資料與報價

旅遊及價格資料為 2026/11/13 的查詢快照，並非即時 API。機票、房價、稅費、行李、停車與取消條件，以供應商結帳頁為準。住宿比較預設 2027/6/1–6/4、兩位成人一間房；更改條件後須重新查價。

舊記帳資料暫以 1 台幣＝40 韓元換算，這是可調整的手動規劃值，不是即時匯率；請按實際換匯或刷卡匯率調整。

地圖、影片、訂購網站與部分圖片需要網路。外部圖片與影片的權利屬各自權利人。
